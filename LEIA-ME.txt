SITE RACHA DA RAC
1. Abra index.html no navegador para visualizar.
2. O botão Livro de regras já usa o link informado.
3. O botão Instagram está desativado até você informar a URL do perfil.
4. O botão Mensalistas abre mensalistas.html, que está pronto para receber fotos e nomes.
5. O PIX é apenas texto, sem botão ou redirecionamento.
6. Para publicar gratuitamente, envie os arquivos da pasta para um repositório público e ative GitHub Pages em Settings > Pages > Deploy from a branch (main, /root).
7. Para ativar Instagram, substitua o elemento <div class="link inactive" ...> por um link <a class="link" href="URL_DO_INSTAGRAM" target="_blank" rel="noopener noreferrer">... </a>.
